# Open Product Format

OPF is an additive OKF profile, not a product-management application or document warehouse.

- Preserve OKF v0.2 trust and provenance.
- Link human intent from EMF; never restate an agent interpretation as human intent.
- Link research from ORF; never silently promote a finding into a product commitment.
- Treat UX journeys, surfaces, states, and interactions as product concepts with outcomes and proof.
- Keep concepts atomic, IDs stable, references resolvable, and packs connected.
- Add a field or rule only for an observed failure; keep the validator stdlib-only.
