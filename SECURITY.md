# Security Policy

## Reporting a vulnerability

Email `daniel@eidosagi.com` with a description, reproduction steps, and likely
impact. Please do not open a public issue for an undisclosed vulnerability.

We will acknowledge reports within 48 hours and aim to resolve critical issues
within seven days. We follow coordinated disclosure and ask reporters to allow
reasonable remediation time before public disclosure.

## Supported versions

Only the latest released OPF version receives security fixes.
